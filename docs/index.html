From board to bedside.

GitHub Pages introduces the project. The ESP32 itself hosts the live control panel on your home network.

01

Connect the hardware

Wire GPIO 25 to the relay input, connect grounds as required by the module, and power the relay from a suitable 5V supply.

GPIO 25 → IN
02

Join your home Wi-Fi

Add your Wi-Fi details to the sketch and upload it. The Serial Monitor prints the ESP32's local IP.

115200 baud
03

Open your local control

Enter that IP above. The link opens the dashboard served by the ESP32, where controls and schedules run.

http://192.168.x.x
A note about local control

The live controls stay on your network.

This public GitHub Pages site cannot directly call the ESP32's plain-HTTP API from its HTTPS page. Use the address field above to open the device-hosted dashboard instead. This keeps the control path local and avoids pretending this showcase page is connected to your light.
